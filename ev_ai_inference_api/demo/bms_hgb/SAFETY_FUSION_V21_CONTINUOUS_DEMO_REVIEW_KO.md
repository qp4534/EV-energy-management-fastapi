# Safety Fusion v2.1 및 연속 BMS 시연 리뷰

## 결론

Hybrid HGB 모델과 물리 임계값은 변경하지 않았다. Safety Fusion에서 하나의
온도 파생 신호가 긴급 후보와 자기 교차확인 근거로 중복 집계되던 문제를
v2.1에서 분리했다. 시연 데이터도 단계별 잘라 붙이기 대신 validation 실험의
연속 1 Hz 구간으로 교체했다.

프론트엔드와 디지털 트윈 출력은 변경하지 않았다.

## 1. Safety Fusion v2.1

기존 v2는 `cell_over_ambient`가 긴급 임계값을 넘으면 `thermal=emergency`와
`corroborated_hot=true`를 동시에 만들어 하나의 신호만으로 최종 긴급이 될 수
있었다.

v2.1은 다음 근거 그룹을 구분한다.

- 국부 고온: 최고온도 또는 온도-주변온도 차이 긴급
- 팩 평균 고온: 평균온도 경고 이상
- 급격한 상승: 30초 상승률 긴급
- 전기 이상: 셀 전압 경고 이상

최종 물리 긴급은 서로 다른 그룹이 2개 이상이거나 열 경고와 전기 경고가
동시에 있을 때만 확정한다. 하나의 물리 신호만 긴급이면 물리 단계는 긴급
후보로 유지하지만 최종 Safety Fusion은 경고로 제한한다.

## 2. 입력 의미 수정

AI-Hub `ambient_temp_c`는 실험 챔버의 주변온도다. 차량 팩 주변온도 또는
냉각수 온도와 동일한 의미라고 보장되지 않으며, Hybrid HGB 필수 6신호에도
포함되지 않는다.

따라서 연속 BMS 시연에서는 이를 차량 물리 규칙의 `ambient_temperature_c`로
전달하지 않는다. 결측값을 조작하거나 대체하지 않고 선택 신호를 `None`으로
명시한다. 실험 챔버 온도는 커넥터 시각화용 중립값으로만 남으며 셀 온도로
사용되지 않는다.

## 3. 연속 시연 데이터

- 출처: AI-Hub validation 실험 `20250825004`
- 구간: 원본 201초부터 786초
- 길이: 586행
- 논리 주기: 1 Hz
- 결측 원본 초: 인접 실측값 사이 선형 보간
- 모델 입력에 원본 단계 라벨 전달: 없음
- 96셀 어댑터: 표면온도 48셀 + 양극단자온도 48셀, 셀 전압 96회 반복

검증 후보 `20250825004`, `20250811005`, `20250820002`를 비교했다. 선택 후보는
가장 짧고, HGB 단계 역행이 없으며, Safety Fusion이 HGB보다 2단계 이상 앞선
시간이 가장 짧았다. 이는 발표 시나리오 선택이며 새로운 성능평가가 아니다.

## 4. 최종 단계 전환

| 논리 초 | HGB | 물리 규칙 | Safety Fusion |
|---:|---|---|---|
| 0~28 | 워밍업 | 정상 | 정상 |
| 29 | 정상 | 정상 | 정상 |
| 120 | 주의 | 정상 | 주의 |
| 180 | 주의 | 주의 | 주의 |
| 305 | 주의 | 경고 | 경고 |
| 541 | 주의 | 긴급 | 긴급 |
| 545 | 경고 | 긴급 | 긴급 |
| 559 | 긴급 | 긴급 | 긴급 |

Safety Fusion이 HGB보다 2단계 앞서는 구간은 4초다. 물리 근거가 실제로 먼저
충족된 구간을 숨기거나 `final=ml`로 강제하지 않았다.

## 5. 검증

- FastAPI 전체 테스트: 158 passed
- 배포 번들 로드 및 계약 검사: 통과
- HGB 네 단계 출력: 정상→주의→경고→긴급
- 프론트 저장소 변경: 없음
- Backend 저장소 변경: 없음
- 커밋·푸시: 수행하지 않음

## 6. 남은 문제

FastAPI 최신 main에서도 `final_risk_level > 0`인 매 프레임마다 새로운
`ANOMALY_LOGS` 행과 보고서 작업을 생성한다. 팀원이 수정했다는 사건 단위
중복 방지는 현재 FastAPI main 코드에서 확인되지 않았다. 통합 시연의 502
재발을 막으려면 이 수정의 실제 브랜치 또는 PR을 별도로 확인해야 한다.

## 7. 한계

- validation 실험을 발표 적합성 기준으로 선택했으므로 이 결과를 독립 성능
  지표로 사용하지 않는다.
- 96셀 배열은 실차 측정이 아니라 결정론적 어댑터다.
- AI-Hub 실험실 라벨과 실제 차량 화재 위험은 동일한 개념이 아니다.
- Safety Fusion v2.1은 프로젝트 연구 프로토타입이며 차량 안전 인증 규칙이
  아니다.
